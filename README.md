# myhealth - AI Health Interface

Welcome to the **myhealth** AI Health Interface repository! This project is an innovative health application built with Next.js and React.

## Overview

myhealth is designed to provide AI-driven health insights and interfaces, serving as a core component of the Ketos SIH AI Health initiative.

## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Tech Stack
- Next.js (App Router)
- React
- Tailwind CSS
- Zustand for state management
- Recharts for data visualization
- Lucide React for iconography
